# Oud website

Open the folder in VS Code and open `index.html` (use the Live Server extension, or just double-click the file).

- `index.html` – page structure
- `css/style.css` – styles and the lighting animation
- `js/main.js` – oud music synth, menu, cart, scroll behavior
- `images/` – dark.jpg (before), lit.jpg (after), pour.jpg (teapot light)

The Google Fonts link in index.html needs an internet connection; the page falls back to Georgia without it.
